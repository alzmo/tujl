OpenAI 发布低资源编程语言评测，聚焦传统软件迁移

OpenAI publishes benchmarks for low-resource programming languages

OpenAI 发布 MultiLangBench，测试模型用20种语言构建 SQLite 兼容引擎，并公布 COBOL 迁移评测。公司报告，GPT-6 Astra 的 MultiLangBench 平均测试通过率为87.4%；GPT-6.1 Sol 在低推理强度下的 COBOL 迁移准确率为86.6%。结果属于厂商自评，生产迁移仍需专家审核和业务测试。

OpenAI introduced MultiLangBench, covering SQLite-compatible engines in 20 languages, alongside a COBOL migration evaluation. It reports an 87.4% average pass rate for GPT-6 Astra and 86.6% COBOL migration accuracy for GPT-6.1 Sol at low reasoning effort. These are vendor evaluations; production migrations still require expert review and business-specific testing.

Deepgram 与 AWS 披露 Trainium2 批量语音推理优化

Deepgram and AWS detail Trainium2 batch-speech optimization

Deepgram 与 AWS 发布 Nova-3 在 Trainium2 上的离线批量推理案例，介绍内核优化和 Rust 并行运行时。双方报告，相比 Deepgram 原有计算方案，每美元处理音频量增加11%–70%。该结果受批量工作负载、配置和评测时价格影响，不代表实时语音任务的普遍收益，也不是当天才完成的迁移。

Deepgram and AWS published a Nova-3 offline-inference case study covering kernel optimization and a Rust parallel runtime on Trainium2. They report 11%–70% more audio processed per dollar than Deepgram’s previous compute options. Results depend on batch workloads, configuration and evaluation-time pricing; they should not be generalized to real-time speech or presented as a migration completed today.

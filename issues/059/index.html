DeepSeek 代理端搜索调用到达免费安排结束的计划节点

DeepSeek agent-side search calls reach their scheduled billing milestone

官方文档规定，通过 DeepSeek Harness、Claude Code 或 Codex 触发的服务器端 Search 与 Fetch 调用，自北京时间11月1日00:00开始按请求计费。两类接口分别为每1000次成功请求0.75美元；需HTTP 200并产生结果，失败、空搜索结果与超时不计费。这里记录官方生效安排，不把它说成今日首次公告，也未用真实账单验证执行情况。

DeepSeek documentation schedules per-request billing for server-side Search and Fetch calls made through DeepSeek Harness, Claude Code or Codex from November 1 at 00:00 Beijing time. Each API lists $0.75 per 1,000 successful requests: HTTP 200 plus a result is required; failures, empty search results and timeouts are not billed. This is the documented effective milestone, not a newly published announcement. Actual billing enforcement has not been tested.

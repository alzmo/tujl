MODELS · 模型发布Meta · 官方研究博客 · 2026.10.12

Meta 发布 Muse Wonder，面向持续工作的智能体

Meta launches Muse Wonder for sustained agent work

Meta 发布 Muse Wonder 与 Muse Wonder Full，强调跨对话检索相关信息的 Active Memory，以及持续推进复杂任务的 Active Focus。官方称，Wonder 已进入 Meta Model API 与 Muse Code，Full 面向 Muse Code 订阅用户；面向 Muse 的上线仍是后续计划。性能优势来自公司评估，本刊未独立复测；不能把“可持续工作”理解成可以不经确认执行所有操作。

Meta introduced Muse Wonder and Muse Wonder Full, emphasizing relevant cross-conversation memory and sustained task execution. Wonder is available through the Meta Model API and Muse Code; Full is available to Muse Code subscribers. A Muse rollout is still forthcoming. Performance claims come from Meta’s evaluations, not our independent testing; persistent execution does not imply unrestricted authority.

INFRASTRUCTURE · 芯片与系统Microsoft · 官方博客 · 2026.10.12

微软公布 Maia 300 与2027年多吉瓦扩展计划

Microsoft outlines Maia 300 and multi-gigawatt expansion from 2027

微软宣布自2027年起将 Azure Maia 扩展到多吉瓦规模。Maia 200 已服务 Copilot 等生产负载；第三代 Maia 300 面向长上下文、解码密集和多步骤智能体任务。微软预计其每兆瓦 token 产出较领先 GPU 系统高40%。这是厂商的目标与比较口径，并非已经完成的全量部署或独立基准结论。

Microsoft plans multi-gigawatt Azure Maia deployments starting in 2027. Maia 200 already serves production workloads including Copilot, while Maia 300 targets long-context, decode-heavy and multi-step agent tasks. Microsoft expects 40% more tokens per megawatt than leading GPU-based systems. This is a vendor projection with its own comparison scope, not a completed rollout or independent benchmark.

OPEN INFRASTRUCTURE · 开放基础设施NVIDIA · 官方博客 · 2026.10.12

NVIDIA 向 OCP 提交 Vera Rubin 机架设计并扩展开源运维组件

NVIDIA contributes Vera Rubin rack designs to OCP and expands open operations tools

NVIDIA 在 OCP 峰会宣布，通过 MGX 开放架构贡献 Vera Rubin 机架与计算托盘设计；MGX 1.2 涵盖盲插液冷、标准化电源与冷却接口，设计支持最高250kW机架。DSX OS 同时增加网络配置、集群就绪检查、机架管理与裸机部署开源组件。这里的“开放”指设计、接口和软件贡献，不代表芯片本身全面开源，也不等于所有设备已互通。

At OCP, NVIDIA contributed Vera Rubin rack and compute-tray designs through MGX. MGX 1.2 includes blind-mate liquid cooling and standardized power and cooling interfaces, supporting designs up to 250 kW per rack. DSX OS also gains open-source components for network configuration, cluster readiness, rack management and bare-metal provisioning. These contributions do not make the chips fully open-source or prove universal interoperability.

Data Agent Kit 把智能体、数据服务与流水线接进 IDE

Data Agent Kit connects agents, data services and pipelines inside the IDE

Google Cloud 介绍 Data Agent Kit：通过编码智能体插件或 VS Code 系 IDE 扩展，组合 MCP 工具、技能与数据开发界面。官方示例贯穿 BigQuery 数据导入、dbt 清洗、模型训练、Spanner 结果检查及 Airflow 编排，并明确要求审阅生成代码、检查评估与运行日志。这是一套产品工作流示范，不是自动化准确率或生产收益的独立实验。

Google Cloud presents Data Agent Kit as a coding-agent plugin or an extension for VS Code-based IDEs, combining MCP tools, skills and data interfaces. Its walkthrough covers BigQuery ingestion, dbt transformations, model training, Spanner inspection and Airflow orchestration. The example calls for code review, evaluation checks and execution-log inspection. It demonstrates a workflow rather than independently measured automation accuracy or production gains.

ANALYTICS · 产品预览Google Cloud · 官方产品公告 · 2026.10.12

Looker Data Apps 开放预览，让生成式应用继承数据权限

Looker Data Apps enters preview with inherited data governance

Google Cloud 宣布 Looker Data Apps 预览：由智能体生成的交互应用可托管于 Looker，并继承语义模型、行级安全与访问控制，还能检查生成 SQL。官方称运行时交互通过原生 Looker API 和模型执行，LLM token 主要在设计生成阶段消耗。这不等于服务免费；预览产品、生成逻辑与写回操作仍需按具体权限和业务规则验证。

Google Cloud announced Looker Data Apps in preview. Agent-generated interactive applications can be hosted in Looker and inherit semantic models, row-level security and access controls, with generated SQL available for inspection. Google says runtime interactions use native Looker APIs and models, with LLM tokens consumed during design and generation. This does not mean the service is free; preview behavior and writeback logic still require validation.

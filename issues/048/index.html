DeepSeek 开源 DeepInfer，公开生产推理引擎核心

DeepSeek opens the core of its DeepInfer inference engine

DeepSeek 公开了支撑其生产服务的 DeepInfer，采用 Apache 2.0 许可，当前支持 DeepSeek-V4.1-Flash，以及 NVIDIA SM100 和华为昇腾 950。开源包提供离线推理、异步调度和结构化输出等能力，但并非完整在线服务，仍需另建 KV 缓存系统、分离式部署及负载均衡。

DeepSeek released DeepInfer under Apache 2.0, exposing the core engine behind its production services. It currently supports DeepSeek-V4.1-Flash on NVIDIA SM100 and Huawei Ascend 950. The package includes offline inference, asynchronous scheduling and structured outputs, but a complete online service still requires additional cache, disaggregated-deployment and load-balancing infrastructure.

Google completes 32-bit Coral NPU and releases compiler 1.0

Google 发布完整的 32 位 Coral NPU 开源设计与基于 IREE/MLIR 的编译器 1.0，连接 JAX、PyTorch 和 TensorFlow 模型与端侧硬件。Synaptics 同步公布 SR200 芯片和 Coralboard SR；Coralboard SL 已进入全球正式供应。最高 1 TOPS 与约 10mW 推理平均功耗是架构配置和设计目标，不应解读为所有设备的实测表现。

Google released the complete 32-bit Coral NPU design and compiler 1.0, using IREE/MLIR to target edge hardware from JAX, PyTorch and TensorFlow. Synaptics announced SR200 silicon and Coralboard SR, while Coralboard SL reached worldwide general availability. The architecture’s up-to-1-TOPS configuration and roughly 10mW average-inference-power target are not universal measured device performance.

ChatGPT 开始推出 Locked Chats，但不等同端到端加密

ChatGPT rolls out Locked Chats, without end-to-end encryption

ChatGPT 开始分批推出 Locked Chats，可将指定对话移出常规历史、置顶和搜索，并通过四位 PIN 或受支持的设备认证打开。锁定不会改变数据保留或模型改进设置，也不会创建端到端加密保险库。重置 PIN 会永久删除此前仅受旧 PIN 保护的聊天及相关内容，使用前应注意这一限制。

ChatGPT is gradually adding Locked Chats, which hide selected conversations from ordinary history, pinned chats and search, with access protected by a four-digit PIN or supported device authentication. Locking does not change retention or model-improvement settings and does not provide end-to-end encryption. Resetting the PIN permanently deletes content protected only by the previous PIN.

AWS 与 i14 展示固定状态的 Laplace 3B 推理方案

AWS and i14 demonstrate fixed-state Laplace 3B inference

AWS 与 i14 介绍了在 Trainium2 上使用原生 PyTorch 训练和部署线性注意力模型 Laplace 3B 的实现。每条序列的循环状态固定为 29.5MB，不随上下文增长；作者报告单实例、1,280 条并发序列下达到每秒 11,544 个输出 token。这是特定配置的厂商测试，固定状态会压缩历史，检索质量仍需按任务验证。

AWS and i14 documented training and serving the linear-attention Laplace 3B model on Trainium2 with native PyTorch. Its recurrent state stays at 29.5MB per sequence. The authors report 11,544 output tokens per second across 1,280 concurrent sequences on one instance. These are configuration-specific vendor results; compressed history still requires workload-level retrieval-quality testing.

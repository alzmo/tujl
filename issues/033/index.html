EVALUATION · 研究预览GitHub · 2026.10.05 · 15:59 UTC

GitHub 发布 ReviewBench，公开 AI 代码审查评测方法

GitHub introduces ReviewBench for evaluating AI code review

GitHub 发布 ReviewBench 研究预览，包含来自187个仓库、覆盖19种语言的219个公开 PR。基准结合人工、模型和静态分析发现的问题，区分精确率、召回率及问题严重性，并公开评测方法。GitHub 报告独立于数据构建的内部工程师复核一致率为96.6%；这属于发布方的验证结果，不代表所有实际代码审查都达到同样可靠性。

GitHub launches the ReviewBench research preview with 219 public pull requests from 187 repositories across 19 languages. It combines human, model and static-analysis findings, separates precision, recall and severity, and publishes its evaluation method. GitHub reports 96.6% agreement in an internal engineer audit independent of dataset construction. That is a publisher-reported validation result, not a reliability guarantee for every real review.

DEVELOPER SECURITY · 官方更新GitHub Changelog · 2026.10.05 · 22:42 UTC

GitHub 密钥扫描新增 Lovable 与 Pydantic AI 网关等检测器

GitHub expands secret scanning to Lovable and Pydantic AI gateway keys

GitHub 公布五类新增密钥检测，涉及 Lovable API、Logfire、Pydantic AI Gateway，以及两类 Supabase 令牌。Lovable 同时加入合作伙伴计划：在公开仓库发现对应密钥时，GitHub 会通知签发方，以便撤销或轮换。检测支持有助于降低 AI 开发工具凭据误提交的风险，但不等于覆盖所有泄露路径，也不保证密钥已自动撤销。

GitHub adds five secret detectors covering Lovable API keys, Logfire tokens, Pydantic AI Gateway keys and two Supabase token types. Lovable also joins the partner program: matching secrets found in public repositories are reported to the issuer for revocation or rotation. Broader detection can reduce exposure from committed AI-tool credentials; it does not cover every leak path or guarantee automatic revocation.

NVIDIA 梳理乳腺医疗 AI 应用，明确部分技术仍在研究阶段

NVIDIA surveys breast-care AI, noting that some technologies remain investigational

NVIDIA 发布 Inception 企业应用综述，涵盖自动超声、乳腺密度评估、数字病理与三维肿瘤可视化。文章介绍 iSono Health、Whiterabbit.ai、Ataraxis AI 和 SimBioSys 的工作，同时注明部分技术尚未获 FDA 商业使用批准。这是厂商对合作生态的介绍，并非当天所有产品的新上市公告或统一临床试验；临床效果与适用范围应按具体产品证据分别判断。

The article explicitly notes that some technologies remain investigational and lack FDA approval for commercial use. This is a vendor ecosystem overview, not a same-day launch of every product or a unified clinical trial; evidence and intended use must be assessed product by product.

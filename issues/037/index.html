Codex 测试输入预测，建议仍由用户确认发送

Codex beta predicts the next message, with sending left to the user

OpenAI 在10月9日更新记录中介绍 Composer predictions：根据当前线程，在输入框提出下一条消息草稿；Tab 接受后仍可修改，不会自动发送。测试版面向支持地区、年满18岁的个人 Pro 用户，需最新版桌面应用及支持的模型和线程类型。预测生成在测试期不计用量，实际发送仍按正常规则计费。

The beta targets adult personal Pro users in supported regions, on the latest desktop app and supported models and thread types. Generating predictions does not consume usage during beta; sent messages follow normal billing.

INFRASTRUCTURE · 开源发布Microsoft · GitHub release · 2026.10.09 · 04:51 UTC

ONNX Runtime 1.31 稳定模型包接口，改进量化推理

ONNX Runtime 1.31 stabilizes model packaging and improves quantized inference

微软发布 ONNX Runtime 1.31.0，将模型包与 EPContext 数据接口转为稳定接口，改进 CPU 模型加载及 INT4/INT8 混合专家推理，并扩大 CoreML 设备选择支持。发布说明提醒核心与执行插件需匹配算子定义；版本更新不意味着任意模型都会提速，实际收益仍依赖模型、硬件和配置。

Microsoft releases ONNX Runtime 1.31.0 with stable model-package and EPContext data APIs, CPU loading improvements, INT4/INT8 mixture-of-experts optimizations and broader CoreML device selection. Release notes warn that core and execution plugins need matching operator schemas. This is a software release, not evidence that every model becomes faster; gains depend on model, hardware and configuration.

COMPUTE · 机构实测Ai2 · Hugging Face · 2026.10.09 · 15:20:29 UTC

Ai2 分享 GPU 预算调度实践，区分占用率与利用率

Ai2 shares budget-based GPU scheduling and distinguishes occupancy from utilization

Ai2 介绍按团队预算、最短运行时间和可抢占时段分配 GPU 的调度实践。机构报告30天测试中交付了应分配 GPU 时数的98%，集群占用率维持98%；调试任务的第90百分位等待由2小时降至30秒。这是该机构自身运行数据，基线样本较少；占用率不等于训练计算利用率，交互会话被抢占也仍是待改善问题。

Ai2 describes GPU scheduling based on team budgets, minimum runtimes and preemptible periods. It reports delivering 98% of owed GPU hours over a 30-day test while maintaining 98% occupancy; debug-job p90 waits fell from two hours to 30 seconds. These are institutional operational measurements with a smaller baseline sample. Occupancy is not compute utilization, and preemption still disrupts interactive sessions.

Darwin-27B-ZTC-v2 发布结构化决策评测结果

The model produces typed decisions and probabilities in one forward pass rather than free text. This records the publisher’s snapshot, not an independent replication. The benchmark does not cover long-form generation or tool use, and probability output alone does not establish reliable calibration in deployment.

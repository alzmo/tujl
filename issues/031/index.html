Aleph Alpha 开放 Kolibri 1，聚焦德英双语与可控推理

Aleph Alpha releases open-weight Kolibri 1 for German-English workloads

Aleph Alpha 以 Apache 2.0 许可发布 Kolibri 1 权重。这个混合专家模型含781亿总参数，每 token 激活约34.6亿参数，支持工具调用和四档推理强度。原生上下文为262,144 token；厂商称已验证可扩展至1,048,576，但建议复杂任务与高效部署使用不超过262,144。扩展效果与性能比较属于厂商测试，不能视为任意任务的保证。

Aleph Alpha releases Kolibri 1 weights under Apache 2.0. The German-English mixture-of-experts model has 78.1B total and 3.46B active parameters per token, tool calling and four reasoning-effort levels. Native context is 262,144 tokens; the company reports validated extension to 1,048,576, while recommending at most 262,144 for complex tasks and efficient serving. Context-extension and performance claims are vendor-tested, not guarantees for every task.

AGENT EVALUATION · 团队实验Microsoft / Hugging Face · 2026.10.03

ThinkingBox 接入 Hugging Face，以数据库最终状态检验智能体

ThinkingBox comes to Hugging Face to test agents against final database state

微软与 Hugging Face 介绍 ThinkingBox 的开放评测环境及 OpenEnv 接口：在507种有状态业务流程中，每个任务独立运行20次，检查最终记录、遗漏和额外副作用。新公告强调一次成功与重复可靠性的差别。底层预印本8月已发布、10月1日修订，尚未确认同行评审；结果来自团队构造的模拟流程，不是实际客户业务的成功率，不能把工具正常返回当成任务完成。

Microsoft and Hugging Face introduce ThinkingBox's evaluation environment through OpenEnv. Across 507 stateful business workflows, each task runs independently 20 times; checks inspect final records, missing changes and unwanted side effects. The new announcement emphasizes repeatability rather than one successful run. Its underlying preprint appeared in August and was revised October 1; peer review is not established. Team-run results on synthetic workflows do not measure success in real customer operations, and a clean tool response does not prove completion.

Google 发布面向工作的 Gemini 智能体

Google announces the Gemini agent for work

Google 宣布统一的 Gemini 工作智能体，可规划任务、调用工具并连接企业系统，在文档、邮件和开发环境中完成工作。公告强调模型选择、成本控制及企业管理机制。这是发布方对产品能力的描述；实际接入仍取决于企业配置、授权与可用范围，不能理解为智能体自动拥有全部业务数据或行动权限。

Google announces a unified Gemini agent that plans tasks, invokes tools and connects to enterprise systems across documents, inboxes and development environments. The announcement emphasizes model selection, cost controls and administration. These are publisher descriptions of capabilities. Actual access depends on enterprise configuration, authorization and availability; an agent does not automatically gain all business data or permissions.

LightOnOCR-3 将文字转录与版面定位合入同一模型

LightOnOCR-3 combines transcription and document layout

LightOn 发布0.8B、1B与4B三种 OCR 模型，采用 Apache 2.0 许可。除文字转录外，grounding 模式还输出带标签的边界框、图像描述和图表数据。厂商报告4B版本在 olmOCR-Bench 得分86.3，并公开复现材料。该成绩及速度比较来自发布方测试，受页面渲染和评测处理方式影响，不代表所有扫描件都能可靠识别。

LightOn releases 0.8B, 1B and 4B OCR models under Apache 2.0. Alongside transcription, grounding mode returns labeled boxes, image descriptions and chart data. The publisher reports an olmOCR-Bench score of 86.3 for the 4B model and provides reproduction materials. Scores and speed comparisons are vendor tests affected by rendering and evaluation choices, not guarantees for every scanned document.

SCIENCE · 研究发布HuggingFaceBio · Gener · 2026.10.08 · 15:13:19 UTC

Carbon-A 发布基因注释模型与候选数据库

Carbon-A releases a genome-annotation model and candidate database

研究团队发布 Carbon-A 及 Carbon Annotation Database，报告在22,617个物种中识别出5.66亿个新的基因候选。模型、训练数据与技术报告开放供检查。团队称已对部分候选开展验证，更多实验结果仍待发布。这里的“候选”是计算预测，不能写成全部基因均已实验证实；技术报告的公开也不等于完成同行评审。

The team releases Carbon-A and the Carbon Annotation Database, reporting 566 million new gene candidates across 22,617 species. Model, training data and a technical report are available for scrutiny. The authors describe validation of some candidates, with further experiments still forthcoming. Candidates are computational predictions, not universally confirmed genes; a public technical report is not evidence of completed peer review.

LOCAL AI · 开源工具Base Compute · Hugging Face · 2026.10.08 · 19:42:19 UTC

Superfluid 为同机多智能体推理加入优先调度

Superfluid adds priority scheduling for local multi-agent inference

Base Compute 发布 Apache 2.0 许可的本地模型服务 Superfluid，支持 llama.cpp、MLX 与 BaseRT，并兼容 OpenAI、Anthropic 和 Ollama 接口。设计重点是让交互请求优先于批处理，并通过日志支持中断恢复。文章的延迟与恢复成绩来自团队指定硬件、模型和并发负载的自测；本刊未复测，也不能由接口兼容推断所有客户端功能均已适配。

Base Compute introduces Superfluid, an Apache 2.0 local model server supporting llama.cpp, MLX and BaseRT, with OpenAI-, Anthropic- and Ollama-compatible APIs. It prioritizes interactive requests over batch work and uses logging for recovery. Latency and recovery results are team-run tests on specified hardware, models and workloads, not independently reproduced here. API compatibility does not establish support for every client feature.

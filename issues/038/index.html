Copilot for JetBrains 增加默认模型与 MCP 启动控制

Copilot for JetBrains adds default-model and MCP startup controls

GitHub 宣布，企业管理员可为新对话指定可用的默认智能体模型，同时保留用户明确选择的模型。新增设置可关闭 Copilot 与 Claude 的 MCP 服务器自动启动；诊断菜单也能将问题交给内联聊天提出修复。插件已停止支持 JetBrains IDE 2025.1，现需2025.2或更高版本。这些是产品控制与兼容性更新，不能据此推断模型能力提升或所有工具调用都已安全。

GitHub says enterprise administrators can set an available agent model as the default for new conversations while preserving explicit model choices. A new setting disables automatic MCP server startup for Copilot and Claude; diagnostic menus can also open inline chat to propose fixes. Support for JetBrains IDE 2025.1 has ended, so the plugin now requires 2025.2 or later. These are product-control and compatibility changes, not evidence of better model performance or universally safe tool use.

Typed Evals 0.2.1 增加 OpenRouter 决策模型接入

Typed Evals 0.2.1 adds OpenRouter decision-model support

Typed Evals 发布0.2.1；当天代码增加可配置的后端地址，并提供经 OpenRouter 调用 Microsoft Decision-1 的示例与契约测试。这个 MIT 许可、Alpha 阶段的 Python 工具可评估回答、RAG 依据和智能体执行记录，并以人工标注校准分数。本期记录的是接入更新，不是工具首次发布。校准仍依赖任务相符的标注与留出验证；新增后端支持也不证明评估准确率提升，本刊未独立运行复测。

Typed Evals releases 0.2.1, adding a configurable backend address plus an OpenRouter example for Microsoft Decision-1 and contract tests. The MIT-licensed, Alpha-stage Python toolkit evaluates responses, RAG evidence and recorded agent runs, with optional calibration against human labels. This is an integration update, not the toolkit’s first release. Calibration still needs task-relevant labels and held-out validation. Supporting another backend does not establish higher evaluation accuracy; we have not independently run or reproduced it.

OpenAI 公布首款自研推理芯片 Jalapeño 的首批测试

OpenAI publishes first results for its custom Jalapeño inference chip

OpenAI 公布其首款自研推理芯片 Jalapeño 的首批测量结果，并计划于年底前开始部署。公司称，在 InferenceX 的公开模型测试中，该系统同时改善了吞吐、功耗与延迟；1.5–1.9 倍每瓦工作量及 1.7–3.6 倍更低端到端延迟等数字来自 OpenAI 的测试，应视为厂商报告，尚待更广泛的独立复现。

OpenAI has published the first measured results for Jalapeño, its first custom inference chip, and plans to begin deploying it by year-end. On public-model tests using InferenceX, the company reports gains across throughput, power, and latency. Figures such as 1.5–1.9× more work per watt and 1.7–3.6× lower end-to-end latency are OpenAI-reported and await broader independent replication.

OpenAI has introduced an Admin plugin for reviewing adoption and credits, managing members and groups, diagnosing access, and handling supported usage requests from ChatGPT Work or Codex. OpenAI says it preserves existing roles and workspace policies rather than granting wider access, with review available for broader-impact actions.

Amazon OpenSearch Service brings trace views into agent conversations with MCP Apps

AWS 宣布 Amazon OpenSearch Service 支持 MCP Apps。工具调用可在 AI 助手内返回交互式追踪瀑布图、服务拓扑和日志模式，便于工程师核对智能体给出的根因判断；数据仍保留在客户自己的 AWS 账户中。

AWS says Amazon OpenSearch Service now supports MCP Apps, allowing tool calls to return interactive trace waterfalls, service maps, and log-pattern views inside an AI assistant. The goal is to make an agent's root-cause hypothesis easier to verify while keeping customer data in the customer's AWS account.

Mary Kay 分享由智能体分诊基础设施事件的运维架构

Mary Kay details an agent-assisted architecture for triaging infrastructure events

Mary Kay 与 AWS 介绍了一套由 AWS DevOps Agent、Amazon Bedrock、Strands SDK 和 AgentCore 组成的运维流程：系统调查事件、分类路由，再由专用智能体提出或执行受控修复。案例称部分事件可在两分钟内形成并合并拉取请求、单次成本约 0.16–0.50 美元；这些是单一企业案例数据，不代表普遍结果。

Mary Kay and AWS describe an operations pipeline built with AWS DevOps Agent, Amazon Bedrock, the Strands SDK, and AgentCore: events are investigated and routed before specialized agents propose or execute controlled fixes. The case study reports some pull requests reaching merge in under two minutes at roughly $0.16–$0.50 per action. These are single-company case results, not general benchmarks.

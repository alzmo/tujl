Site owners can allow supported agents, block them on pages with ads or block them entirely, separately from search and training policies. The company notes that identifying an agent does not reveal what its user authorized; carrying that context remains future work.

Cohere Embed 5 与 Rerank 5 接入 OpenRouter

Cohere brings Embed 5 and Rerank 5 to OpenRouter

Cohere 宣布 Embed 5、Rerank 5 的 Pro 与 Fast 版本可通过 OpenRouter 使用。Embed 5 支持文本、图像及混合输入，Pro 与 Fast 共用嵌入空间，可分别承担建库与查询。此次更新是新增接入渠道，并非两款模型首次发布；质量与延迟取舍仍需用实际数据验证。

Embed 5 accepts text, images and mixed inputs; Pro and Fast share an embedding space, enabling Pro indexing with Fast queries. This is a new access channel, not the models’ initial release. Quality and latency trade-offs still need testing on real workloads.

Dharma-AI 介绍 20 亿参数文档字段提取器，输出结构化 JSON

Dharma-AI introduces a 2B document field extractor for structured JSON

Dharma-AI 的 Field Extractor 可从文档图像开放提取字段，也可按指定 schema 输出 JSON。团队自建评测涵盖546份文档、1,638个案例，报告综合得分0.834。质量优势属于厂商自测；其 GPU 运行成本与商业 API 标价口径不同，不能直接当作产品售价或普遍优势。

Dharma-AI’s Field Extractor supports open field extraction and schema-directed JSON from document images. Its own benchmark covers 546 documents and 1,638 cases, with a reported composite score of 0.834. Quality advantages are vendor-tested. Its GPU runtime cost comparison uses a different basis from commercial API list prices and is not a product price or a universal advantage.

智能体治理说明 / Agent-governance explainerAWS Machine Learning Blog · 2026.11.04 · 仅日期，时间/时区未披露 / date only

AWS 详解 Amazon Quick 智能审批如何保留人工控制

AWS explains how Amazon Quick Smart Approvals preserves human control

AWS 解释已于10月28日推出的 Smart Approvals：在既有权限内审查符合条件的操作，批准仅对应被审查的具体动作与参数。拒绝规则和强制人工审批继续生效，评估失败会交还用户。11月4日发布的是机制说明；AWS 同时承认自动分类可能出错。

AWS explained Smart Approvals, launched on October 28. It reviews eligible actions within existing permissions, with approval tied to the exact action and parameters examined. Denial rules and mandatory human checks remain, and failed reviews return to the user. The November 4 article is an explainer, not a launch; AWS acknowledges that automated classification can be wrong.

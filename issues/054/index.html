GPT-6.1 Terra 发布，侧重电脑操作与效率

GPT-6.1 Terra focuses on computer use and efficiency

OpenAI 发布 GPT-6.1 Terra，面向视觉理解、电脑操作和高频工作，并在 Work、Codex 与 API 提供。API 每百万 token 标价为输入 1 美元、缓存输入 0.05 美元、输出 5 美元。官方称标准价格较 GPT-5.6 Terra 与 GPT-6.1 Sol 低 50%；能力与速度比较属于公司自测，不代表所有实际任务。

OpenAI introduced GPT-6.1 Terra for visual understanding and computer-based work, available through Work, Codex and the API. Published API prices per million tokens are $1 for input, $0.05 for cached input and $5 for output. OpenAI says standard prices are 50% below GPT-5.6 Terra and GPT-6.1 Sol. Performance and speed comparisons are vendor evaluations, not guarantees for every workflow.

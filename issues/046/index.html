vLLM 0.32.0 发布：扩大低精度缓存支持，同时调整兼容边界

vLLM 0.32.0 expands low-precision caching and changes compatibility

正式版本增加通用工具与推理解析器，扩展低精度KV缓存和多模态模型支持，并包含安全修复。升级同时停止支持Python 3.10、收紧默认CORS来源范围。发布说明中的吞吐提升来自特定模型、硬件与请求条件下的项目测试，不是普遍加速保证；部署前应核对兼容性和自己的负载。

The release adds generic tool and reasoning parsers, expands low-precision KV caching and multimodal model support, and includes security fixes. It also drops Python 3.10 and restricts default CORS origins. Throughput improvements in the notes come from project benchmarks with specific models, hardware and requests; they are not universal speedup guarantees. Compatibility and workload testing remain necessary.

endue 整合智能体云电脑，并加入跨智能体任务协调

endue integrates agent cloud computers and task coordination

官方发布说明称，每个智能体可在独立Station中按需启动Linux和Chrome工作空间，空闲时停止、再次启动时保留文件；运行费用使用统一积分余额。新增的秘书入口负责分派与汇总任务，MCP调用可按智能体开放权限。这是服务方公布的功能，不是本刊完成的可靠性或安全性实测，持续运行仍受费用和授权条件约束。

The vendor says each agent can start Linux and Chrome workspaces inside its own Station, retaining files across idle shutdowns and charging a shared credit balance. A secretary coordinates delegated tasks, while MCP access can be enabled per agent. These are announced features, not reliability or security tests performed by TUJL; ongoing operation remains subject to costs and permissions.

PUBLIC BENEFIT · 待批准承诺Anthropic · 官方公告 · 2026.10.18 · 仅核实日期 / date only

Anthropic 拟将5%股权投入新公益基金，仍待股东批准

Anthropic proposes a 5% equity commitment to a new public-benefit fund

Anthropic 宣布设立全资有限责任公司形式的Public Benefit Fund，初始5%股权投入需股东批准。公司称估值每较设定基线上升50%，董事会可酌情再增加2%；具体基线与治理安排将后续公布。公告列举向非营利机构捐助或特定群体直接分配等可能用途，但这不是已经发放的资金，也不应直接换算成已兑现的公益成果。

Anthropic announces a wholly owned LLC, the Public Benefit Fund, with an initial 5% equity commitment subject to stockholder approval. Its board may add 2% for each 50% increase in company value above a set baseline; the baseline and governance details are to follow. Possible uses include nonprofit grants or direct distributions. This is a conditional commitment, not money already distributed or a demonstrated social outcome.

LOCAL AI · 开发分支Hugging Face · 2026.09.22

Transformers 接入 GGUF 量化推理，先支持 Apple Silicon

Transformers adds packed GGUF inference, starting with Apple Silicon

Hugging Face 介绍通过 ggml 内核在 Transformers 中直接运行压缩的 GGUF 权重，保留熟悉的模型加载与生成接口。首批重点是 Apple Silicon 的 MPS 后端及 Qwen3.5 系列；文章要求使用开发主分支，填充与批处理仍有限制。没有兼容内核时会回退到解量化，不能理解为所有硬件和模型都已获得同等支持。

Hugging Face describes running packed GGUF weights inside Transformers through ggml kernels while retaining familiar loading and generation APIs. Initial support focuses on Apple Silicon's MPS backend and Qwen3.5 models. The article requires the development main branch and notes padding and batching limits. Without a compatible kernel, loading falls back to dequantization; support is not universal across hardware or models.

BENCHMARKS · 开发者发布Basecompute / Lukas Wesemann · 2026.09.22

Compute:Arena 将本地推理成绩与测试条件放在一起

Compute:Arena pairs local inference results with their test conditions

开发者发布公开排行榜与命令行工具，为模型文件、量化格式、芯片和运行程序记录身份及哈希，并保存温度、电源和内存等测试条件。测试可离线完成，提交前可查看将公开的数据。作者明确说明：报告签名只能证明签名后未被改动，不能证明机器报告真实；不同运行时的预热与执行顺序也不完全相同。

The developer introduces a public leaderboard and CLI that identify model files, quantization formats, chips, and runtime binaries, alongside temperature, power, and memory conditions. Tests can run offline, with public data reviewed before submission. The author explicitly cautions that signatures establish integrity after signing, not truthful machine reports, and that runtime warmup and execution order are not identical.

This announces maintenance arrangements and direction, not a new model release or an already demonstrated inference-speed improvement.
